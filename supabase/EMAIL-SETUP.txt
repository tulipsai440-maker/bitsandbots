JOIN FORM EMAIL
=============

Recipient: suresh440@gmail.com

OPTION A — Works now (no API key)
  The form uses FormSubmit.co automatically when RESEND_API_KEY is not set.

  ONE-TIME SETUP:
  1. Submit the Join form once at http://localhost:8080/join
  2. Check suresh440@gmail.com for email from FormSubmit
  3. Click "Activate Form" in that email
  4. Submit the Join form again — join requests will arrive by email

OPTION B — Resend (better for production)
  1. Sign up at https://resend.com with suresh440@gmail.com
  2. Create API key → add to .env:
       RESEND_API_KEY="re_xxxxxxxx"   # from Resend dashboard — never commit real keys
       RESEND_FROM="Bits & Bots <onboarding@resend.dev>"
  3. Restart npm run dev
  Resend takes priority over FormSubmit when configured.

PARENT BROADCAST (Admin → Broadcast)
  Without a domain (recommended now):
    Use “Open Gmail (BCC all)” — loads every unique parent email in BCC; click Send once.

  WhatsApp auto-send (no opening the app):
    Requires WhatsApp Business Cloud API + parent phones. See supabase/WHATSAPP-SETUP.txt.
    Button: “Send WhatsApp to all parents”.
    Group invite links still only support copy + open (manual paste) — Meta does not allow auto-send to a group via invite URL.

  With Resend auto-send to everyone:
    Verify a domain at https://resend.com/domains, then set
      RESEND_FROM="Bits & Bots <hello@your-verified-domain.com>"
    and restart. Until then Resend can only email your Resend account address.

  Optional once: run supabase/setup-broadcast.sql to store the WhatsApp group link.

PRODUCTION
  Set SITE_ORIGIN to your live Worker URL (also in wrangler.toml [vars]):
    SITE_ORIGIN="https://bitsandbots.sravanthi440.workers.dev"
  Or your custom domain once attached.
