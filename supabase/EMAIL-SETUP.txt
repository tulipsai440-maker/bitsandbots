PARENT BROADCAST (Admin → Broadcast)
====================================

One button: **Send email** — emails every unique parent address via Resend (BCC).

REQUIRED: verify fllbots.com in Resend (one-time)
-------------------------------------------------
1. Open https://resend.com/domains
2. Click **fllbots.com** (or **Add domain** → `fllbots.com`)
3. Copy the DNS records Resend shows (SPF TXT, DKIM CNAMEs, optional MX)

4. Open Cloudflare → **fllbots.com** → **DNS** → **Records**
5. For each Resend record, click **Add record**:
   - Match **Type**, **Name**, and **Content** exactly from Resend
   - Leave **Proxy status** = DNS only (grey cloud) for email records
6. Back in Resend, click **Verify** — status should turn **Verified**

7. Set sender address (local `.env` + Cloudflare Worker secret):
     RESEND_FROM="Bits & Bots <updates@fllbots.com>"

8. Redeploy or restart dev server after changing secrets.

Test: Admin → Broadcast → subject + message → **Send email (N)**.
