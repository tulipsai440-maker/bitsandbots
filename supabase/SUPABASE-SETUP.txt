STEP 6 — Make yourself admin (NOT about password)
-------------------------------------------------
Admin access is a database role, not a special password.
  - Password = can sign in at /auth
  - Admin = row in public.user_roles with role = 'admin'

SQL Editor → open grant-admin.sql
Replace REPLACE-WITH-THEIR-EMAIL@example.com with your signup email → Run
(For trivarn440@gmail.com use grant-admin-trivarn440.sql instead.)

Verify in SQL Editor (expect 1 row):
  SELECT u.email, r.role
  FROM public.user_roles r
  JOIN auth.users u ON u.id = r.user_id
  WHERE lower(u.email) = lower('YOUR-EMAIL@example.com')
    AND r.role = 'admin';

Sign in at http://localhost:8080/auth as that same email, then open
/admin/calendar (or other admin pages) and refresh.
If you still see "Admin access required", you are signed in as a different
account or the role row is missing — re-run the verify SELECT above.

Also run setup-troop-admins.sql once if you want Admin → Team Admins
(UI for granting admin without SQL).
